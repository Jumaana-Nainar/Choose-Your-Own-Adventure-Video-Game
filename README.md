# Age of Adventure
A choose-your-own-adventure web-based video game built using HTML, CSS, and JavaScript as a final project for a Grade 11 computer science course. With an 8-bit theme accompanied by sound effects and simple storyline, this game provides a unique experience for each user based on their decisions at various stages throughout.


Key gameplay components:
* Storyline driven by user decisions
* Character animations, scrolling background, and sound effects
